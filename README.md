# 🚀 JavaScript Functions Practice

## JSE#4

A JavaScript practice project focused on defining, calling, and working with functions. It covers parameters and return values through examples such as calculating a mean and checking credentials; storing and passing functions as values (1st-class members); function expressions, callbacks, and higher-order functions; closures; object methods and this; arrow functions; array methods including forEach, filter, and map; and default parameters with an immediately invoked function expression (IIFE). This project forms part of my study and preparation workflow for the **JavaScript Certified Entry-level (JSE)** certification.

## 📌 Core Learning Objectives

- Declare and call functions with parameters and return values.
- Use function expressions, including anonymous functions.
- Treat functions as values and pass them as callback arguments.
- Create higher-order functions and closures.
- Define object methods and understand how `this` refers to the current object.
- Write arrow functions and recognize how they differ from regular functions.
- Use array methods such as `forEach()`, `filter()`, and `map()` with functions.
- Set default parameter values.
